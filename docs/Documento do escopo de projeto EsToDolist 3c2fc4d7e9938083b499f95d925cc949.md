# Documento do escopo de projeto EsToDolist.

## Objetivo do projeto:

O projeto EsToDoList tem como gerenciar trabalhos de SENAI, provas da escola e tarefas do dia a dia, para facilitar nossa organização. É uma ferramenta criada para ajudar o estudante.

## Requisitos funcionais:

- Adicionar Tarefas.

Para adicionar tarefas o usuário deve fornecer informações como: Nome, data e hora.

- Editar Tarefas de forma rápida.

O usuário poderá clicar na tarefa pra poder editar ela podendo alterar nome, data e hora da tarefa.

- Excluir o que não é mais necessário.

O usuário pode apagar tarefas no sistema clicando no ícone de lixeira. O sistema apenas irá pedir a confirmação da exclusão.

- Marcar Tarefas como Concluídas com um clique

Para o usuário ver se ele fez aquela tarefa e se organizar ele terá que clicar no ícone de confere para dar um check na tarefa e marcar ela como feita.

- Pesquisar e filtrar para encontrar qualquer tarefa em segundos.

Para o usuário encontrar a tarefa que ele quer ele poderá pesquisar na barra de pesquisa ela vai filtrar pelo nome da tarefa e poderá filtrar pela data também.

## Requisitos não funcionais:

- Responsividade

O usuário não precisa ter um computador para poder acessar a ferramenta.

- Fácil de usar

Como se trata de uma ferramenta para facilitar a vida do estudante então ele tem que ser fácil de usar.
